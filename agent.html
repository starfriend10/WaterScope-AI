How to use & sample queries

Before Agent search

  • Clear selected papers under Selected for chat (or click below) before asking Agent to find new papers — otherwise chat uses your current selection instead of starting a new search.
  • Agent mode (checkbox) can automatically search and retrieve publications when nothing is selected; Find requests leave the returned papers unselected for you to review.
  • Manual search on the left keeps your checkboxes until you clear them.

Papers are selected — Agent will chat about these, not run a new search. Clear first to find new papers.

Search syntax

  • +term required · -term exclude · "exact phrase"
  • Natural language: microplastics in freshwater, not drinking water
  • Use Top 50 for broader discovery — results show 10 at a time with arrow navigation (10 of 50, 20 of 50, …).
